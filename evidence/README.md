# Evidence

This folder contains screenshots collected during the Linux authentication log investigation.

## Evidence Files

- `failed-login-attempts.png` — Shows the failed authentication attempts identified in the log.
- `failed-logins-by-ip.png` — Shows failed login attempts grouped by source IP address.
- `successful-logins.png` — Shows successful authentication events.
- `authentication-timeline.png` — Shows the chronological sequence of failed and successful authentication attempts.
